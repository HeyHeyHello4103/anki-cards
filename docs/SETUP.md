# 公開までの準備（管理者向け）

この手順は最初の1回だけ必要です。作業は **GitHub** と **Firebase** の2か所で行います。

---

## 1. GitHub（サイトの公開場所）

1. このリポジトリの **Settings → Pages** を開きます。
2. 「Build and deployment」の **Source** を **GitHub Actions** にします。
3. `main` ブランチに変更が入るたびに自動で公開されます。公開先のURLは同じ画面に表示されます。
   - 例：`https://ユーザー名.github.io/anki-cards/`

> リポジトリは公開（Public）ですが、中にあるのはプログラムだけです。カードと学習記録は Firebase に保存されていて、登録した人しか読めません。

---

## 2. Firebase（ログインとデータ保存）

### 2-1. プロジェクトを作る

1. <https://console.firebase.google.com> で「プロジェクトを作成」を押します。
2. 名前は自由です（例：`anki-cards`）。Google アナリティクスはオフで構いません。
3. 料金プランは無料の **Spark** のままで使えます。上限を超えても自動で課金されることはありません。

### 2-2. ログイン方法を有効にする

1. 左のメニューから **Authentication** を開き、「始める」を押します。
2. **ログイン方法** タブで次の2つを有効にします。
   - **メール/パスワード**：「メール/パスワード」だけをオンにします（「メールリンク」はオフのまま）。
   - **Google**：オンにし、「プロジェクトのサポートメール」に自分のアドレスを選びます。
3. **設定** タブ → **承認済みドメイン** → 「ドメインの追加」で、`ユーザー名.github.io` を追加します。
   - これを忘れると、Googleログインで「このサイトのドメインがFirebaseで許可されていません」と表示されます。
4. （おすすめ）**Templates** タブで、確認メールなどの言語を **日本語** にします。

### 2-3. データベースを作る

1. 左のメニューから **Firestore Database** を開き、「データベースを作成」を押します。
2. ロケーションは **asia-northeast1（東京）** を選びます（あとから変更できません）。
3. **本番環境モード** を選んで作成します。

### 2-4. アクセスのルールを設定する

1. Firestore Database の **ルール** タブを開きます。
2. 中身をすべて消して、このリポジトリの [`firestore.rules`](../firestore.rules) の内容を貼り付け、「公開」を押します。

このルールにより、次のようになります。

| | カード | 自分の学習記録 | ほかの人の学習記録 | 利用者の名簿 |
|---|---|---|---|---|
| 登録していない人 | 読めない | — | 読めない | 読めない |
| 利用者 | 読むだけ | 読み書き | 読めない | 自分の分だけ確認 |
| 管理者 | 読み書き | 読み書き | 読むだけ | 読み書き |

### 2-5. 最初の管理者（あなた）を登録する

利用者の登録は管理画面からできますが、最初の管理者だけは Firebase コンソールで登録します。

1. Firestore Database の **データ** タブで「コレクションを開始」を押します。
2. コレクション ID：`members`
3. ドキュメント ID：**ログインに使うメールアドレス（すべて小文字）**
4. フィールドを2つ追加します。
   - `role`（型：string）＝ `admin`
   - `name`（型：string）＝ 一覧に出す名前（例：`先生`）
5. 保存します。

### 2-6. 設定値をアプリに入れる

1. 左上の歯車 → **プロジェクトの設定** → 「マイアプリ」でウェブアプリ（`</>`）を追加します。「Firebase Hosting も設定する」はオフで構いません。
2. 表示される `firebaseConfig`（`apiKey` などの値）を、[`src/firebaseConfig.ts`](../src/firebaseConfig.ts) に入れます。
   - これらの値は公開しても問題ありません。データの保護は上のルールで行っています。

---

## 3. 使い始める

1. 公開されたURLを開き、2-5で登録したメールアドレスでログインします。
   - メールアドレスで登録した場合は、確認メールのリンクを開いてから「確認しました」を押します。確認メールは迷惑メールフォルダに入ることがあります。
2. **管理 → カード** から、カードのCSVを取り込みます（形式は下記）。
3. **管理 → 利用者** で、使う人のメールアドレスを登録します。
4. 使う人にURLを伝えます。
   - LINE で送ると、LINE の中のブラウザでは Google ログインができません。このサイトは自動で普段のブラウザ（Safari・Chrome）で開き直すようにしていますが、うまくいかない場合は「ブラウザで開く」を選んでもらってください。
   - スマホではブラウザのメニューから「ホーム画面に追加」すると、アプリのように使えます。

## カードのCSVの形式

1行目に見出しを入れます。列の順番は自由です。

| 見出し | 必須 | 内容 |
|---|---|---|
| ID | | 空欄なら自動で付きます。書き出したCSVでは入っています |
| 科目 | ○ | 例：英語、国語、地理 |
| セット | | 学習するときの単位。空欄なら「全般」（「単元」という見出しでも読めます） |
| 区分 | | セットを開いたときに絞り込む単位（例：第1問）。空欄なら区分なし |
| 表 | ○ | 問題 |
| 裏 | ○ | 答え |
| 解説 | | 答えの下に小さく表示します |
| タグ | | 空白で区切って複数書けます |

「問題」「答え」「教科」など、よく使われる別の見出しでも読み取れます。

### 書き方

| 書きたいもの | 書き方 | 表示 |
|---|---|---|
| 数式 | `$y=x^2-4x+3$` | 文中に数式 |
| 大きな数式 | `$$\int_0^1 x\,dx$$` | 独立した行の数式 |
| 化学式・反応式 | `\ce{CH4 + 2O2 -> CO2 + 2H2O}` | 化学式（`$` で囲んでも可） |
| 太字 | `**重要**` | **重要** |
| 改行 | セルの中で改行 | 改行 |
| 数式ではない `$` | `\$` | $ |

### 取り込み前の点検

取り込む前に、次の点を自動で点検して一覧にします。

- **要修正**（直すまで取り込めません）：表・裏・科目の空欄、同じIDの重複
- **要確認**（そのまま取り込めます）
  - 同じ問題なのに答えが違うカード（答えが一つに定まらない）
  - 同じ問題と答えのカードの重複
  - 全角・半角や空白だけが違う問題文・科目名・単元名（表記ゆれ）
  - 数式の書き方の誤り
  - 長すぎる答え（200文字超）
  - 表と裏が同じカード

### カードを直すとき

少しの修正なら、**管理 → 編集** でその場で直せます。

- **セットと区分の整理**：セット・区分・科目の名前の変更、セットどうしのまとめ、区分のまとめ・ほかのセットへの移動、並びの変更、セットの削除
- **カードを探して直す**：文字やセットで探して、表・裏・解説・区分を直す。1枚ずつの追加・削除

どれもカードのIDは変わらないので、学習記録はそのまま残ります。

たくさんのカードをまとめて直すときは、CSVを使います。

1. **管理 → カード →「登録済みカードをCSVで書き出す」** でCSVを保存します。
2. Excel などで直します。ID列は消さないでください。学習記録はIDで引き継がれます。
3. 保存して取り込みます。消したカードも反映したいときは、「このファイルにない登録済みカードを削除する」にチェックを入れます。

Excel で保存するときは「CSV UTF-8（コンマ区切り）」がおすすめです。普通の「CSV（コンマ区切り）」でも読み込めます。
